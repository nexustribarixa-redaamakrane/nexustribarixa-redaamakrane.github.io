Font Modding

fModLoader (FML)

fModLoader (FML) (v1.0.6 BETA "Project Horde" / v1.0.4 BETA "Project Vectoris") is an open-source desktop application for dynamic font glyph modification on Windows. Built with a modern C# (.NET Core + Avalonia UI) architecture, it enables font artists, modders, and language script engineers to create, edit, and apply custom glyph modifications onto compatible font files without commercial editors.

Key Architectural Features

  • Built-in C# Vector Font Editor: Full FontForge-inspired glyph canvas with 13 drawing tools in Avalonia UI, including Bezier Pen (smooth/corner anchor toggling), Knife tool with Bezier intersection detection, Node editor, Freehand Pencil, and Ruler tool with real-time distance and angle readout.
  • GlyphData C# Vector Model: Strongly typed C# models (PathNode, GlyphContour, GlyphData, ModProject) providing clean MVVM separation between UI and data.
  • ModProject Serialization: Full .ttfm / .otfm ZIP-based project save and load with metadata validation and SVG vector import/export.
  • Script Execution Environment: Embedded execution environment supporting Python, FontForge .pe, and Cython scripts.
  • Custom File Picker: Advanced ui_file_dialog with bookmark access, navigation history, and dynamic type filtering.
