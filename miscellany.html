SocioProgram

Socioprogram is an anti-bloat social media platform built for software developers to share projects, code snippets, and engineering discussions without algorithmic distortion or clout metrics ("contributions over clout").

Features & Principles

  • Anti-bloat & Anti-ads: Strict chronological feed order, zero advertisements, and zero algorithmic engagement bait.
  • Aggregated Feeds: Integrates Reddit and GitHub activity alongside original user-generated posts.
  • Tech Stack & Auth: Built with Flask (Python 3.13), SQLAlchemy, SQLite, HTML/CSS/jQuery, OAuth SSO (Google, GitHub, Reddit), and TOTP 2FA (Google Authenticator compatible).
  • Production Status: Fully functional web application deployed on PythonAnywhere (decommissioned legacy OSINT honeypot forks to ensure pure production code).

Repository & Setup

git clone https://github.com/nexustribarixa-redaamakrane/socioprogram.git pip install -r requirements.txt python app.py
