RCCR

RCCR (Reddit Conlang Code Registry) is the official registry for assigning conflict-free BCP 47 subtags and metadata layers to conlangs and neographies. Where RNUR records where a project's glyphs live, RCCR records which language or writing system produced a given piece of text.

Current State

  • Specification: RCCR-TS-01 — Conlang Code Registry Architecture Specification, version 1.1.0, status Draft.
  • Registry data: data/registry.csv currently holds 9 registered tags — 7 conscript tags (art-x-sx-*) and 2 conlang tags (art-x-*).
  • Tag rules: conscripts take art-x-sx-<slug> and conlangs take art-x-<slug>. A conlang whose language already carries a BCP 47 primary subtag — such as hil or en — is registered as a conscript only, and no language tag is minted for it.
  • RNUR cross-reference: every registry row carries the RNUR codepoint range backing the tag, for example art-x-sx-franklin at U+EE00–U+EE0F and the art-x-sx-placeholder cipher script at U+F5C0–U+F71F.
  • Provisional status: all current entries are marked Provisional Lease / Pending Upstream Ratification.
