Linguistics & Unicode

SuperUnicode (SUCS / ExtSUCS)

SuperUnicode (SUCS / ExtSUCS) is a fully custom character encoding designed from the ground up for the OpenWindows Operating System — it is not derived from or related to the Unicode standard. Similarly, SUTF (transformation formats) and SUST (serialization transports) are custom text transformation and serialization layers built specifically for OpenWindows — they are not derived from or related to UTF. Implemented in freestanding C99 (-std=c99 -nostdlib -ffreestanding), the library distinguishes strictly between numerical character encodings, logical transformation formats, and physical serialization transports.

Custom Encodings & Custom Transports

  • Base SUCS (31-bit): Address space from 0x00000000 to 0x7FFFFFFF with kernel security trap ranges (0x7FFFFFF0–0x7FFFFFFE).
  • ExtSUCS (64-bit): Unbounded address space implemented via 64-bit container types with out-of-band error handling.
  • SUTF Transformation Formats (not UTF): Strictly transformation formats defining the endian-neutral mapping between SUCS codepoints and symbol sequences — they do not define physical byte ordering or framing. Includes SUTF-8 (1 to 6 byte variable stream), SUTF-16 (1 or 2 16-bit words, no surrogates — 0xD800–0xDFFF are valid PUA codepoints), SUTF-4 (4-bit hex nibble debugging console), SUTF-2 (2-bit symbol frames for IPC thread channels), and vSUTF (variable multi-byte streaming for the full 64-bit ExtSUCS space).
  • SUST Serialization Transports (not UTF): The physical serialization layer. Includes SUST-16 (canonical big-endian serialization of the SUTF-16 word stream, 2 or 4 bytes per codepoint, no BOM), SUST-32 / SUST-64 (4B / 8B fixed vector slot transports for SIMD and AI alignment), SUST-128 / 256 / 512 / N (16B / 32B / 64B / N-byte aligned vector transports for SSE/AVX), and e-SUST (hypervisor page-mapped virtual IPC transport with 4096-codepoint pages and a 6-byte IPC frame). All are proprietary OpenWindows formats.
  • Kernel Mode Controller (sucs_mode.h): Manages reboot-committed mode switching between Base and Extended operating modes.
