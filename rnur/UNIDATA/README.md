# RNUR UNIDATA (Mirror)

This folder is a **mirror** of the `UNIDATA` folder from the
[RNUR repository](https://github.com/nexustribarixa-redaamakrane/rnur).

It provides a Unicode Character Database of the scripts in RNUR (and shared
registries). Still under construction.

When these files are modified, they are updated from the
[RNUR GitHub page](https://github.com/nexustribarixa-redaamakrane/rnur).
